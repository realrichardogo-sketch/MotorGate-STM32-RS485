# PPP03 M13：RS485 状态读取

## 本阶段目标

保持 M12 的本地按键、限时控制、编码器边沿关断和 57 边沿阈值。在电机板上启用 Modbus RTU 从站，先用 RS485 **读取**诊断状态。本阶段不允许远程启动、停止或修改设定；保留原有 3 号键本地停止。

网关板的程序尚未提供。本工程**只能烧录到 64 KB 电机板**，不能烧录到网关板。网关接入需要网关固件，或暂用 USB 转 RS485 适配器接电脑测试。

## 接口参数和接线

- 电机板：Modbus RTU 从站地址 `1`，`115200` 波特率，`8N1`，CRC16；支持功能码 `04`。地址配置固定在本阶段固件中，未读取卖家的 EEPROM 地址设置。
- 供电断开时按**实物丝印**确认两板 RS485 端子；所提供的两份原理图都标 `485A`、`485B`、`GND`。A 接 A、B 接 B、GND 接 GND。若 PCB 实物没有引出或端子未安装，先停在接口确认，不要碰 P2（P2 是 SWD 接口），也不要按线色猜。
- 首次通信仅用两块板各自既有的**逻辑供电**，拔下金属电源的交流插头，保持电机动力电源断开。网关板目前没有提供主站固件，仅将线接通不代表网关会自动查询。
- 若用电脑验证，使用具有 RS485 A/B/GND 端子的 USB 转 RS485 适配器，通过 Modbus RTU 主站软件查询电机板；USB 转 TTL 串口不能直接接 RS485 A/B。没有适配器时先做下面的无动力烧录自检。

## 输入寄存器映射

功能码 04，**主站请求起始地址为 0**，连续读 10 个 16 位寄存器。部分主站软件将同一个地址显示为 `30001`，请核对软件的“地址基数”选项。

| 请求偏移 | 值 | 说明 |
| --- | --- | --- |
| 0 | 13 | 固件阶段号 |
| 1 | 0–7 | 状态：0 READY、1 ARMED、2 RUN、3 STOP、4 DONE、5 NO ENC、6 FAULT、7 OVRSPD |
| 2 | 15–25 | 目标转速 S，单位 RPM |
| 3 | 实际转速 | 屏幕 R，整数 RPM |
| 4 | 最终边沿 D | 本次短行程计数；停止后的短暂滑行可能更新 |
| 5 | 关断边沿 F | PWM 关闭时计数 |
| 6 | 滑行边沿 K | `D - F` |
| 7 | ADC 原始值 A | 未换算电流，不能用作过流保护阈值 |
| 8 | PWM 比较值 C | 调试信息 |
| 9 | 上电秒数 | 16 位循环计数，可用来确认数据持续更新 |

读到 13 和递增的上电秒数才算通信通过。写单寄存器、写多寄存器、写线圈等处理器在本阶段已禁用；通信请求不能启动电机。

## 上板步骤

1. 保存已经通过的 M12 工程与 HEX。在 Keil 打开 `MDK-ARM/PPP03_motor_hal.uvprojx`，执行 **Rebuild**，确认 `0 Error(s)`，核对新 HEX 的文件名和生成时间，然后仅烧录电机板。本压缩包不带 HEX。
2. 电机动力电源保持断开，只接逻辑供电：OLED 应显示 `M13:READY`；双按 1 号键后约 0.4 秒显示 `M13:NO ENC`，按 3 号键显示 `M13:STOP`。这一阶段先不做动力测试。
3. 若备齐 RS485 主站和已确认的端子，断电接线后上电，以地址 `1`、`115200 8N1`、功能码 `04` 从偏移 `0` 读取 `10` 个寄存器；核对偏移 0 为 `13`，偏移 9 随时间增加。写命令应报非法功能或被拒绝，电机不能被远程启动。
4. 若超时，依次核查主站串口/波特率/从站地址、板子是否有 RS485 收发器和端子、A/B 丝印及共地；排查时始终断开动力电源。
