# PPP03 M10：停机瞬间计数与滑行诊断

## 当前实测与本次改动

M9 已经在固定电机、空载、S20 条件下让输出轴转过约 95°；一次 `T15 D062`，另三次为 `T15 D061`、`T14 D064`、`T14 D061`。目标仍为 **59 个编码器上升沿**，每 50 ms 判断一次是否达到目标。

M10 **暂不修改转动方向、PWM 占空比、59 脉冲目标、停止方式或保护阈值**。它只增加一个停机瞬间的软件计数快照，以便区分检查周期内的多转与停机后的滑行。

OLED 显示：

- `M10:DONE`：到达原有 59 脉冲目标后已关闭驱动；`STOP`、`NO ENC`、`FAULT`、`OVRSPD` 含义沿用 M9。
- `T`：50 ms 更新次数；`D`：本次最终累计边沿（`DONE` 后最多继续更新 500 ms）。
- `C`：最后 PWM 比较值；`F`：发出关闭驱动命令时锁存的软件边沿计数；`K`：`D - F`，即关闭后编码器新报告的边沿数。
- `S`、`R`、`A`：设定转速、测得转速、ADC 原始值。为留出 `F`、`K` 的位置，OLED 本版不显示旧版的 `B/P/E`；其采样和原有函数仍保留。ADC 未校准为安培，不能用作已经验证的过流保护。

例：`M10:DONE T15 D062`、`C548 F060 K002` 表示每 50 ms 的检查在不少于 59 个脉冲时关断桥臂，软件锁存 `F60`，之后 500 ms 内继续测得两个边沿。若 `F` 已高于 59，则差值含有检查周期的滞后；`K` 包括关闭后计数，但捕获中断的处理延迟也可能使它包含关断前已经到来的边沿，因此只是**滑行估计**，不能当作精确机械制动距离。

## 烧录与验收

1. 将当前已验证的 M9 工程和 HEX 留存。断开电机动力电源，在 Keil 中打开 `MDK-ARM/PPP03_motor_hal.uvprojx`，执行 **Rebuild**，确认 0 errors，并检查编译生成的 HEX 路径与时间。使用 ST-LINK Utility 将**本次刚生成的 HEX** 仅烧录到 64 KB 电机板；此包不附带旧 HEX。
2. 只接逻辑供电：应显示 `M10:READY`。不接电机动力供电时，双按 1 号键仍应约 0.4 秒后显示 `M10:NO ENC`；按 3 号键显示 `M10:STOP`。确认 F、K 为 000。若状态不符，不接动力电源。
3. 电机与相机固定、输出轴无负载，轴端/固定端参照线可见；金属电源交流端已有防触及措施，直流接线沿用此前验证的配置。接通电机动力供电，设置 `S20`，身体和线缆远离轴，仅运行一次短行程。待电机停稳至少 1 秒后，记录状态、`T D C F K` 和起止角度。运行中不要触碰轴或改变接线。
4. 预期显示 `M10:DONE`，`F >= 59`、`D >= F` 且 `K = D - F`；角度仍约为上一版 95°。随后可重复两次验证这三组计数。若出现意外方向、无法停机、异常噪声或 `NO ENC/FAULT/OVRSPD/STOP T20`，断开动力电源，保留读数再分析。

## 下一步判读

- 若多次 `F` 为 59～60、`K` 约 2～4：停机后的计数占主要部分，后续可试验提前关断并重新实测实际轴角。
- 若多次 `F` 为 62～64、`K` 为 0：50 ms 周期检查使关断时已越过 59，后续优先评估缩短检查周期或在捕获回调中安全关断。
- 其他结果先保留原始数据再决定修改，不凭一次观察直接改 59 脉冲目标。精度验收以输出轴参照线为准，编码器与减速比只用于估算。
