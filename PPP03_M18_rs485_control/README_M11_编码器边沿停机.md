# PPP03 M11：在目标编码器边沿停机

## 基线与本次实验

现场 M10 空载 S20 试转得到 `M10:DONE T16 D065 C548 F062 K003`：目标 59 个边沿，50 ms 周期检查时已数到 62，随后又收到 3 个边沿。M11 将 **59 个边沿** 的关断判断移至 TIM4 编码器捕获回调，尽量减少 50 ms 检查周期造成的额外转动。**只改变目标达成时的触发时机，不预先修改目标或引入反向制动。**

TIM2 原有的 50 ms 调速、最多 T20（约 1 秒）的运行上限、8 个无新边沿周期的无编码器关断、连续超速关断、ADC 读取失败关断和 3 号键停机保留。原有 `SHUTDOWN` 关断路径不变。TIM2 与 TIM4 在当前工程配置中为同一中断优先级；捕获回调若要等待正在处理的 TIM2 更新中断，关断仍有中断处理延迟，不能保证恰在物理第 59 个边沿的同一瞬间关断。

## OLED 字段

- `M11:DONE`：达到目标边沿并已发出关断命令；`T` 为已完成的 50 ms 定时更新次数，事件发生在两次更新之间时 T 不会反映小数部分。
- `F`：发出关断命令后记录的软件边沿数，通常应接近 **059**；`D`：停机后最多再记录 500 ms 的边沿总数；`K = D - F`：关断后新报告的边沿数，可能包含因中断处理延迟而迟报的物理边沿。
- `C`、`S`、`R`、`A` 延续前版。显示使用一次短暂的计数快照，使同一屏的 `D`、`F`、`K` 满足 `D = F + K`，避免运行中读到混合的两次数据。
- `B/P/E` 在 M10 起已不占用 OLED 行，原有 ADC 采样代码仍在；原始 ADC 未转换成电流，未构成校准后的过流保护。

若滑行数仍约 K003，则预期 `F059 D062 K003`，对应输出轴约 95°（11 边沿/电机转、约 21.428:1 减速比的估算）；以轴端标记的实际停位为准。M11 这一步先单独核实事件触发，尚未将目标改低以补偿滑行。

## 上板顺序

1. 备份已验证的 M10 HEX；断开动力电源，打开 `MDK-ARM/PPP03_motor_hal.uvprojx` 在 Keil 执行 **Rebuild**，确认 0 errors。从本工程目录读取新生成的 HEX，只烧录 64 KB 的电机板。本包不附旧 HEX。
2. 仅接逻辑供电，上电应显示 `M11:READY`；无电机动力供电双按 1 号键，约 0.4 秒应显示 `M11:NO ENC`，按 3 号键显示 `M11:STOP`。异常则不接动力电源。
3. 电机牢固固定、输出轴无负载、端面和固定外壳的参照标记可见；金属电源交流端做好防触及保护，直流接线与前次成功试转一致。接通动力电源，保持 S20，所有人和线缆离开轴，只启动一次短行程。停稳 1 秒后记录状态、`T D C F K` 与实际角度，试验中不触碰轴。
4. 只有在显示 `M11:DONE`、`F >= 59`、`D = F + K`、实际角度仍是小于一圈的短转动时才继续比较结果；若出现 `STOP T20`、`NO ENC`、`FAULT`、`OVRSPD`、方向错误或不停机，立刻停止测试并断开动力电源，记录读数。

## 如何决定后续补偿

与 M10 的 `F062 K003 D065` 比较。如果 M11 的 F 靠近 59 而 K 仍约 3，表明检查间隔的误差已减小，下一阶段才考虑有限幅度地提前关断并做小样本验证。若 F 仍高于 59 或 D 与实测角度不符，先排查编码器计数和中断时序；不得只按旧读数改目标。
