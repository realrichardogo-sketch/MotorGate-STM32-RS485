# PPP03 M12：两脉冲滑行补偿

## 依据与改动

M11 在相同的 S20 空载条件下，连续三次记录 `F059 K002 D061`。以编码器约 11 个边沿/电机转和减速比约 21.428:1 估算，四分之一输出轴圈约 59 个边沿；M11 的实际停位略超过 90°。本版将捕获回调中的**关断目标从 59 改为 57 个边沿**，预计滑行 2 个边沿后得到 `D059`。这是基于已测条件的试验参数；实际角度必须由轴端标记再次验证，不能把补偿视作已证明的各种负载下的精度。

M11 的 TIM4 边沿触发关断、TIM2 50 ms 调速、最长 20 次更新（约 1 秒）限制、无编码器、超速、ADC 读取失败和 3 号键停止路径全部沿用。驱动关闭方式不变，不做主动制动。OLED 状态前缀改为 `M12`，字段 `T D C F K` 沿用，`D = F + K`；ADC 原始数 `A` 不能直接当电流。

## 上板验收

1. 保存已经通过的 M11 工程与 HEX；拔下电机动力电源。用 Keil 打开 `MDK-ARM/PPP03_motor_hal.uvprojx` 执行 **Rebuild**，确认 0 errors，核对新生成的 HEX 路径和生成时间，并只烧录至 64 KB 的电机板。本 ZIP 不含旧 HEX。
2. 只接逻辑供电，上电应显示 `M12:READY`；不接动力电源时双按 1 号键，应约 0.4 秒显示 `M12:NO ENC`；按 3 号键应能停机。异常则不继续动力测试。
3. 电机固定、输出轴空载、轴端及端盖的参照标记清楚可见；交流接线端做好防触及保护，直流接线使用前次验证过的接法。S 保持 **20**。接通动力电源，手和线缆离开轴，启动一次短行程。停稳至少 1 秒后记录 `状态、T、D、C、F、K` 和标记对应的实际角度。测试时不要用手扶电机。
4. 预期 `M12:DONE F057` 左右，若滑行仍为 `K002`，则 `D059`，实际约 90°。出现 `NO ENC`、`FAULT`、`OVRSPD`、`STOP T20`、方向不对、机械抖动或停位明显不合理，立即停止、断开动力电源、记录数据，暂不重复运行。

## 后续判断

先比较这一轮的实际轴角和 `D`，再进行两次同条件重复验证。若 K 与角度保持接近，M12 可作为空载短行程阶段结果；若 K 变化较大，需要基于实际变化分析速度、供电和负载，不能把固定减 2 的目标推广到其他工况。电流采样尚无 V2.1 板对应校准与过流阈值。
