# PPP03 M9：输出轴约四分之一圈

## 本阶段目的

此前 M8 在 S20、最长 1 秒的空载试转中获得 `T20 D078 C546`，电机按时停机。M9 用已标定的编码器脉冲累计值，让电机达到预定小角度后**提前断开桥臂**。编码器盘在转子尾部；先前手动标定约 11 个上升沿/转子圈，减速比约 21.428:1，因此四分之一输出轴圈约 11 × 21.428 / 4 = 58.927 个边沿，目标取 **59 个**。

本版本是有边界的空载定位实验，目标是验证“接近四分之一圈并自动停机”的功能。控制器按 50 ms 周期判定目标，且机械轴可能继续滑行；不能承诺实际轴角精确为 90°。OLED `D` 在 `M9:DONE` 后最多继续记录 500 ms 的编码器滑行边沿，因此读到的 D 可能大于 59。出现 `DONE` 后等至少 1 秒再记录 D，不要用手移动轴。

## 保护和显示

- 维持 M8 的 S15/20/25、C540～560、最长 T20（1 秒）停机、连续 8 个周期无编码器停机、有效测速连续 3 次达到 45 RPM 则超速关断锁定、3 号键立即停机和 ADC 故障停机。
- 运行中每 50 ms 检查累计边沿；第一次读到至少 **59** 时关闭桥臂，状态显示 `M9:DONE`。由于检查周期，关闭时可能已经多出几个边沿；若 1 秒到时仍未达到，则是 `M9:STOP T20`，不能记为定位成功。长时间没有边沿显示 `M9:NO ENC`。
- 第二行：状态、T（50 ms 周期数）、D（本次编码器边沿数）；第三行：S、R、A；第四行：C、B、P、E。A/B/P/E 仍是 ADC 诊断计数，没有实物板 V2.1 校准资料，不能设置过流阈值。状态行示例 `M9:DONE T15 D063`。
- 禁止堵转或挂载机械负载；本阶段只做一次短时空载定位。

## 上板验收

1. 先备份 M8 的 HEX，并**断开动力电源**。在 Keil 中打开 `MDK-ARM/PPP03_motor_hal.uvprojx` 执行 Rebuild；确认 0 errors，Flash 64 KB 空间够用。从本次工程输出目录读取刚生成的 HEX，使用 ST-LINK Utility 只烧录到 **64 KB 的电机板**。本包不放旧 HEX。
2. 只接逻辑电源，屏幕应显示 `M9:READY`。双按 1 号键后应约 0.4 秒显示 `M9:NO ENC T08`；按 3 号键应显示 `M9:STOP`。若这一步不对，先不连接动力电源。
3. 拔掉金属电源市电插头，待其停止工作，在输出轴端面画一条细线，在固定的机架上画一条参考线；固定电机，输出轴没有负载，给交流接线端做好防触及处理，检查动力电源与主板此前验证的直流接线一致。
4. 接通动力电源，将 S 设为 20。身体和线缆远离轴，双按 1 号键**仅试一次**。预期约 0.7～1 秒内显示 `M9:DONE`，轴从参考线附近转过约四分之一圈并停下。等待 1 秒再记录显示的 `T、D、C`，并观察实际停止位置；若 `M9:NO ENC`、`M9:FAULT`、`M9:OVRSPD`、`M9:STOP T20`、方向错误或未及时停止，先断开动力电源并记录，不继续试转。

## 下一步的判断

用 `D` 与轴上标记的实际角度对照。如果 D 达标而实际角度误差明显，先分析减速比标定、机械惯性和 50 ms 检查周期，再决定是否进一步改成更快的捕获停止或滑行补偿。电流采样与过流保护需要对应 V2.1 电路和独立测量，保持为并行硬件核验；M9 不依赖它提供未经校准的保护。

## 本地验证范围

已经用主机 GCC 对修改代码做语法检查并检查 ZIP 完整性；本地没有 Keil ARMCC 或实物电机可运行。OLED 前缀 `M9` 是确认正确烧录的依据。
